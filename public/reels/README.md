# Reels & Latest Looks — video files

Drop 3 short vertical video files (MP4, ideally under ~8MB each so they load fast) into this folder with these exact filenames:

- `reel-1.mp4` — Kid's Cut
- `reel-2.mp4` — Full Transformation
- `reel-3.mp4` — Fresh Style

Once a file is added here and deployed, its tile on the website automatically starts autoplaying that video (muted, looping) instead of the placeholder — no code changes needed. If a file is missing, that tile falls back to a clickable placeholder linking to the matching reel on Instagram, so nothing ever looks broken.

**Where to get the video:** open the reel in the Instagram app → tap the ••• menu → Save/Download. AirDrop or transfer the saved video file with that exact filename into this folder.

**Recommended:** keep videos short (under 15 seconds) and compressed for the web — large files slow down page load for visitors.
